# Phase 4 — SEO, social metadata, favicon

Follows phases 1–3 on `polish/structure`. Same rules: no build step, keep the
Win98 aesthetic, don't touch `CNAME` / `BarathanAslanCV.pdf` / FormSubmit `_next`.

## Why this matters here specifically

The CV now renders from `cv.json` via JavaScript, so **the CV text is no longer in
the HTML source**. Googlebot executes JS and will still index it, but link-preview
scrapers (LinkedIn, WhatsApp, Slack, iMessage) generally do not. A portfolio is
shared on exactly those surfaces, so the metadata below is doing real work, not
box-ticking.

## Required

### 1. `<head>` metadata in `index.html`

Currently the only `<meta>` is `viewport`. Add:

- `<meta name="description">` — one sentence, ~150 chars, written from the CV
  profile. Must read as a human sentence, not a keyword list.
- `<link rel="canonical" href="https://barathanaslan.com/">`
- Open Graph: `og:type` (`profile`), `og:url`, `og:title`, `og:description`,
  `og:image`, `og:image:alt`, `og:site_name`.
- Twitter: `twitter:card` = `summary_large_image`, plus title/description/image.
- `<meta name="author" content="Barathan Aslan">`
- Keep `<title>` as-is unless there's a clear reason; it is already correct.

`og:image` must be an **absolute** URL (`https://barathanaslan.com/...`) —
relative paths break on most scrapers.

### 2. Favicon

None exists today. Use the vendored Win98 iconography so it matches the site:
add `<link rel="icon">` pointing at a local PNG in `assets/`. Provide a 32x32
at minimum. Also add `apple-touch-icon` (180x180) so a home-screen bookmark
isn't a blank page thumbnail.

### 3. OG preview image

Create `assets/og-image.png` at **1200x630**. The obvious and on-brand choice is
a clean screenshot of the Win98 desktop with the CV window open. Must be legible
when scaled down to a small preview card — check that the name is readable.

### 4. `<noscript>` fallback

If JS is unavailable the CV window renders empty. Add a `<noscript>` block with
name, role, location, contact, and a link to `BarathanAslanCV.pdf`. This is also
what non-JS scrapers will read.

### 5. Link the real PDF

`BarathanAslanCV.pdf` is currently an orphan — nothing links to it. Since it now
holds the current CV, expose it (e.g. a "Download PDF" affordance near the
existing Export PDF button). Keep the Win98 button styling.

### 6. `robots.txt` + `sitemap.xml`

Trivial for a one-page site but cheap and correct. Sitemap lists the single URL.

## Verify

- View source and confirm every tag is present with absolute URLs.
- Validate the card renders: check `og:image` resolves at its absolute URL and is
  1200x630.
- Confirm the favicon appears in the browser tab.
- Confirm `<noscript>` content is present in the raw HTML (`curl` the page and
  grep — it must be in the source, not injected).
- Desktop rendering unchanged.
