# barathanaslan.com

My personal site: a Windows 98 desktop with my CV on it, and things to play
with around it — Minesweeper, Solitaire, an MS-DOS prompt, Notepad, wallpapers,
and a My Computer window that shows which of my computers are awake right now.

https://barathanaslan.com/

Hand-written HTML, CSS and JavaScript with no build step and no frameworks,
served by GitHub Pages. Window chrome from [98.css](https://github.com/jdan/98.css).
The live machine status is relayed by a small Cloudflare Worker in `status/`;
visitors only ever read a cached summary.

Architecture notes are in [docs/overview.md](docs/overview.md).
